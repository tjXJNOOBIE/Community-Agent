Community Agent / Discord Manager is not submission-ready from the current public `main` branch. The complete E2E implementation could not be recovered from authoritative Git/Tavall/recovery sources, and no physical Discord test-guild acceptance is claimed.

## Intended project

An AI-powered Discord community operator for trusted organizers: community observation, support/event/moderation proposals, explicit operator approval, deterministic Discord mutations, fresh verification, and auditability. It is not an anonymous chatbot.

## Strands and safety

The intended architecture uses a Strands coordinator and specialists above deterministic Discord capability handlers. Discord content is untrusted observation by default. Approval and trust-policy mutation remain outside model-facing MCP.

## Disclosure

The intended project would reuse the pre-existing Strands SDK, shared Strands bridge, Discord/MCP libraries, and Tavall development infrastructure. Those reused components must be disclosed separately from hackathon-built product code.
